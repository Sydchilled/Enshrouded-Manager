Get your server running — one button

This installs everything it needs, creates your server, and starts it. It's safe to click even if you've already run it before — it'll just update things and restart.


    

  


  

    
Once it's running

    
Give your friends your address and this port so they can find you in the Steam server browser:
      15637. Share the password above with people you want to let in.
      Use the Dashboard tab any time to stop, start, or check on the server. Everything else
      (fine-tuning gameplay rules, backups, logs) lives under the Advanced tabs — you don't need
      them to just play.

  






  

    Known limitations (confirmed during setup): Enshrouded has no RCON, no admin console, and no
    remote save/kick — those only work in-game. There is also no confirmed graceful-shutdown command, so
    Stop and Restart below hard-kill the process. The game's own autosave runs
    roughly every 10 minutes regardless, and the Backups tab adds an independent copy on top of that.

Paths

    
SteamCMD and the game install are kept in separate folders on purpose — running steamcmd.exe
      from inside the game's own folder is a known way to make it nest the install under
      steamapps\common\... instead of honoring the install directory below.

    

      
      
      
      
    

    
Browse buttons open a native Windows folder picker, so they
      only work when this manager is actually running on Windows — type the path in by hand here instead.

    

      
      
    

    
"Save paths" just remembers the folder. "Import existing install from this folder" also
      checks that enshrouded_server.exe is actually there and loads its
      enshrouded_server.json if it's ever been run — use that one when adopting a server you already
      have.

    

  


  

    
Already running a server the old way? Import your .bat file

    
If you've got an existing bare-bones install — a plain enshrouded_server.exe
      started by double-clicking a simple .bat file — paste that file's contents (or pick the file)
      below. This reads both the .bat file and, once it's found the folder, your existing
      enshrouded_server.json, and tells you plainly whether the import succeeded.

User groups

      
Up to 10 groups. Whoever connects with a group's password gets that group's permissions —
        there's no separate admin login. A player with "can kick/ban" cannot be removed by another admin except by
        changing that group's password and restarting the server.

      

      

        
      

    

    

      
Banned accounts

      
Bans are normally added in-game by a group with kick/ban rights; this list is the persisted
        result. Edit with care.

      
    

  


  

    

      
Raw JSON

      
Full control, including any fields not covered above. Some third-party tools mention extra
        top-level fields (e.g. gamePort, bindIP, a top-level password) that
        couldn't be confirmed against official docs — if your real generated file has them, edit them here.
